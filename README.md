# Soundify

Play sounds on specific events. Everything is configurable in the settings menu.

For using this while developing, check out the Makefile.

If you are using the plugin and want to suggest new features / found bugs, please open an issue on Github.

## Note:

Obsidian asset distribution doesn't allow me to distribute the default media pack I wanted to include with the plugin.

So until I get the time to make a fix, please download media.zip from the latest release and drop it in the plugin folder available in your vault in .obsidian/plugins/soundify.
