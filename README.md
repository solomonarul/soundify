# Soundify

Play sounds on specific events. Everything is configurable in the settings menu.

If you are using the plugin and want to suggest new features / found bugs, please open an issue on Github.

## Usage:

- (optional) download the preset _media.zip_ from the latest release and put it in the __.obsidian/plugins/soundify__ folder.
- load the plugin once for the folders to generate.
- you can select in the settings for every event any __.mp3__ file available in the __.obisidian/plugins/soundify/media/<event_name>__ folder.
